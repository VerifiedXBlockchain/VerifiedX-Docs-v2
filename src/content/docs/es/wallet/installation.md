## macOS
1. **Descarga**: abre la [versión más reciente de la GUI de VerifiedX](https://github.com/VerifiedXBlockchain/VerifiedX-GUI/releases/latest) y descarga el DMG para tu Mac: `VFX-OSX-ARM-Installer.dmg` para Apple silicon o `VFX-OSX-Intel-Installer.dmg` para Intel.
2. **Abre el archivo**: haz doble clic en el archivo descargado para abrirlo.
3. **Instala la aplicación**: arrastra y suelta la aplicación VFXWallet (VerifiedX Switchblade) en tu carpeta Aplicaciones.
4. **Abre la aplicación**: abre VFXWallet desde la carpeta Aplicaciones. La primera vez, macOS confirma que la aplicación se descargó de internet; selecciona “Abrir”.

El instalador está firmado y notarizado por Apple, así que no es necesario cambiar ninguna configuración de seguridad. Los instaladores anteriores a la versión 8.0.2 no estaban notarizados; si macOS se niega a abrir uno, descarga el instalador actual.

## Windows
1. **Descarga**: abre la [versión más reciente de la GUI de VerifiedX](https://github.com/VerifiedXBlockchain/VerifiedX-GUI/releases/latest) y descarga `VFXWalletSetup-64.exe` (Windows de 64 bits).
2. **Ejecuta el instalador**:
   - Haz doble clic en el archivo EXE para iniciar la instalación.
   - Sigue el asistente de configuración en pantalla para completar la instalación.
3. **Atiende los avisos de seguridad**:
   - Si Windows Defender te lo pide, haz clic en “Ejecutar de todas formas” (Run Anyway).
   - Permite la aplicación en tu firewall si es necesario.
   - Si hace falta, haz clic derecho en el instalador y selecciona “Ejecutar como administrador” (Run as Administrator) para asegurarte de que todos los componentes se instalen correctamente.

## Linux y la web

No hay instalador de escritorio para Linux. En Linux, o en cualquier dispositivo con navegador, usa la [billetera web](/es/wallet/web-wallet/) en [wallet.verifiedx.io](https://wallet.verifiedx.io).
