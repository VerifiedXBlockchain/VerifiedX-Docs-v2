## Funciones
- Funcionalidad totalmente autocustodiada.
- Accesible desde cualquier navegador.


## Nota de seguridad
Tus claves privadas nunca salen de tu dispositivo. Todas las transacciones se firman localmente.

## Primeros pasos
1. **Crea o importa**:
   - Usa una combinación de correo y contraseña para generar una cuenta.
   - También puedes importar una frase de recuperación o una clave privada existente.
2. **Funciones**:
   - La billetera web admite todas las funciones principales de la aplicación GUI, excepto la validación.
