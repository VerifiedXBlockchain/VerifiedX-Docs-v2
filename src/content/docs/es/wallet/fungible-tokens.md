## Crear tokens
1. **Configuración**:
   - Define un nombre y un ticker para tu token.
   - Elige entre un suministro infinito o fijo.
2. **Personalización**:
   - Preemite tokens si lo deseas.
   - Agrega un ícono on-chain para identificarlo fácilmente.

## Herramientas de administración
- **Emisión**: genera tokens adicionales (si el suministro es infinito).
- **Gobernanza**: habilita temas de votación para los poseedores del token.
- **Controles**: pausa transacciones, bloquea direcciones y transfiere la propiedad con un clic.
