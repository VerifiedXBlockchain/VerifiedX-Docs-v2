## vBTC V2 Technical Specification

Revised edition for VerifiedX Core 9.0: the key ceremony and its on-chain binding, Bitcoin attestation, vault accounting, consensus-fixed withdrawals, key maintenance, S3C, transaction types, parameters and network heights, and the protocol's security properties and assumptions. It replaces the edition withdrawn in September 2026.

## vBTC.b Technical Specification

Version 4 of the vBTC.b contract on Base, as it runs on testnet (Core `ee83f568`, November 2026): the two signer groups and their thresholds, EIP-712 typed messages, minting, exits to VerifiedX and to Bitcoin, timelocked governance, the upgrade from V3, and the security model. Base mainnet runs V3 until its upgrade.
