## Features
- Full self-custodial functionality.
- Accessible via any browser at [wallet.verifiedx.io](https://wallet.verifiedx.io) (testnet: [wallet-testnet.verifiedx.io](https://wallet-testnet.verifiedx.io)).


## Security Note
Your private keys will never leave your device. All transactions are signed locally.

## Getting Started
1. **Create or Import**:
   - Use an email/password combination to generate an account.
   - Alternatively, sign in with an existing mnemonic phrase (HD account), a VFX private key, a Bitcoin private key or WIF key, or the VFX browser extension.
   - The network does not store your email/password or mnemonic. They are used as seeds to generate your VFX account, vault account and Bitcoin account keys.
2. **Features**:
   - The web wallet supports the core features of the GUI app: send and receive, vault accounts, domains, vBTC, fungible tokens, smart contracts and NFTs, and P2P auctions. Validating, Privacy (shielded VFX) and Operations are only in the desktop app.
