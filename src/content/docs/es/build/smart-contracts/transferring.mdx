Endpoints de la API:

Transferir sin URL de respaldo para los archivos multimedia:

```text
GET http://localhost:7292/scapi/scv1/TransferNFT/{id}/{address}
```

Transferir con URL de respaldo para los archivos multimedia:

```text
GET http://localhost:7292/scapi/scv1/TransferNFT/{id}/{address}/{backupUrl}
```

#### Parámetros de la URL:

`id`: el identificador del contrato inteligente

`address`: la dirección de VFX del destinatario

`backupUrl`: URL de un respaldo de los archivos multimedia fuera de la red (opcional)

#### Respuesta:

```json
{
  "Result": "Success",
  "Message": "NFT Transfer has been started."
}
```

La transferencia se ejecuta en segundo plano después de esta respuesta. El nodo necesita un beacon almacenado para subir los archivos multimedia para un destinatario que no está en su propia billetera; de lo contrario, responde `{"Result": "Fail", "Message": "You do not have any beacons stored."}`. Otros errores también vuelven con `"Result": "Fail"` y un `Message`.

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const transferNft = async (smartContractUid, address) => {
  const url = `${CLI_BASE_URL}/scapi/scv1/TransferNFT/${smartContractUid}/${address}`;
  const request = await fetch(url);

  const data = await request.json();
  return data["Result"] == "Success";
};
```
