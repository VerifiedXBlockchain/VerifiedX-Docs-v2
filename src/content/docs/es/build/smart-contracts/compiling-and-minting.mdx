## Descripción general

Compilar y emitir un contrato inteligente es bastante sencillo. El primer paso es compilar el contrato inteligente a partir de un payload JSON, que devuelve la información necesaria para el segundo paso: emitir el contrato inteligente. Luego llamas a un endpoint para emitirlo, que transmite la transacción.

Trillium no tiene gas ni medición de ejecución, pero la transacción de emisión igual paga la comisión normal de la red VFX según su tamaño, que se quema. El objeto `Transaction` de la respuesta de compilación muestra la `Fee` que pagará la emisión.

## Compilación

#### Endpoint de la API:

```text
POST http://localhost:7292/scapi/scv1/CreateSmartContract
```

Ejemplo de payload básico:

```json
{
  "Name": "Smart Contract Name",
  "MinterName": "Minter's Name",
  "Description": "Description Goes Here",
  "SmartContractAsset": {
    "AssetId": "00000000-0000-0000-0000-000000000000",
    "Name": "welness.jpg",
    "AssetAuthorName": "Author's Name",
    "Location": "/path/to/asset.jpg",
    "Extension": "jpg",
    "FileSize": 1024
  },
  "IsPublic": false,
  "SmartContractUID": "00000000-0000-0000-0000-000000000000",
  "Features": [],
  "MinterAddress": "Rabc123..."

  }
```

## Emisión

#### Endpoint de la API:

```text
GET http://localhost:7292/scapi/scv1/MintSmartContract/{SMART_CONTRACT_UID}
```

Ejemplo de respuesta:

```text
"Smart contract has been published to mempool"
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const mintNft = async (smartContractUid) => {
  const url = `${CLI_BASE_URL}/scapi/scv1/MintSmartContract/${smartContractUid}`;
  const request = await fetch(url);

  const data = await request.text();
  if (data == "Smart contract has been published to mempool") {
    return true;
  }

  return false;
};
```

</TabItem>

<TabItem label="Python">

```python
def mint_nft(smart_contract_uid):
    url = f"{CLI_BASE_URL}/scapi/scv1/MintSmartContract/{smart_contract_uid}"
    response = requests.get(url)
    data = response.text

    if data == "Smart contract has been published to mempool":
        return True

    return False

```

## Agregar funciones

Puedes agregar funciones a tu contrato inteligente con solo incluirlas en el arreglo `Features: []`.
Hay tres tipos de funciones de NFT que puedes definir con este payload, cada una con un valor distinto del enum `FeatureName`:

```text
0: Evolving
1: Royalty
2: Multi Asset
```

:::note[Varias funciones]
Puedes combinar las tres funciones en un solo contrato inteligente, pero no puedes incluir la misma función más de una vez.
:::

### Regalía

#### Porcentaje

```json
{
    ...
    "Features": [
        {
            "FeatureName": 1,
            "FeatureFeatures":{
                "RoyaltyAmount": 0.05, // 5%
                "RoyaltyPayToAddress": "Rabc123...",
                "RoyaltyType": 1
            }
        },
    ]
}
```

`RoyaltyAmount` es una fracción y debe ser menor que 1 (0.99 como máximo).

:::caution[Regalías fijas]
Las regalías fijas (`RoyaltyType: 0`) ya no se aceptan. `CreateSmartContract` las rechaza con "Flat rates may no longer be used." Usa una regalía porcentual (`RoyaltyType: 1`).
:::

### Consultar los datos

Una vez que el contrato inteligente se compila y se emite, puedes volver a leerlo a través de la API. Estos endpoints devuelven solo contratos de cuentas de la billetera de este nodo, nueve por página.

#### Listar

```text
GET http://localhost:7292/scapi/scv1/GetAllSmartContracts/{PAGE}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const listNfts = async (page = 1) => {
  const url = `${CLI_BASE_URL}/scapi/scv1/GetAllSmartContracts/${page}`;
  const request = await fetch(url);

  const data = await request.json();

  if (!data) {
    return null;
  }

  if (data["Count"] == 0) {
    console.log("No NFTs found");
    return [];
  }

  return data["Results"];
};
```

</TabItem>

<TabItem label="Python">

```python
def list_nfts(page=1):
    url = f"{CLI_BASE_URL}/scapi/scv1/GetAllSmartContracts/{page}"
    response = requests.get(url)
    data = response.json()

    if not data:
        return None

    if data["Count"] == 0:
        print("No NFTs found")
        return []

    return data["Results"]
```

#### Buscar

```text
GET http://localhost:7292/scapi/scv1/GetAllSmartContracts/{PAGE}/false/false/{QUERY}
```

Los dos segmentos `false` son `excludeToken` y `tokensOnly`. Una ruta de dos segmentos como `GetAllSmartContracts/1/{QUERY}` se interpreta como `excludeToken` y falla con un error de validación 400.

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js

  const url = `${CLI_BASE_URL}/scapi/scv1/GetAllSmartContracts/${page}/false/false/${query}`;
```

```js
const retrieveNft = async (smartContractUid) => {
  const url = `${CLI_BASE_URL}/scapi/scv1/GetSingleSmartContract/${smartContractUid}`;

  if (!data || data.length < 1) return null;

};
```
