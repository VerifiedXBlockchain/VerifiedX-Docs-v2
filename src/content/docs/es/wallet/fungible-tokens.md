## Crear tokens
1. **Configuración**:
   - En **Tokens fungibles**, haz clic en **Crear token** y define un nombre y un ticker para tu token.
   - Elige entre un suministro infinito o fijo. Un suministro total de 0 significa suministro infinito, lo que permite emitir.
   - Define los decimales y elige si el token es quemable y si permite votación.
2. **Personalización**:
   - Preemite tokens si lo deseas.
   - Sube un ícono del token para identificarlo fácilmente. El ícono es obligatorio.
3. **Despliegue**:
   - Haz clic en **Compilar y emitir** para desplegar el contrato inteligente del token. Su configuración no se puede cambiar después.

## Herramientas de administración
- **Emisión**: genera tokens adicionales (si el suministro es infinito).
- **Quema**: destruye los tokens que tienes (si el token es quemable).
- **Gobernanza**: habilita temas de votación para los poseedores del token.
- **Controles**: pausa transacciones, bloquea direcciones y transfiere la propiedad con un clic.
