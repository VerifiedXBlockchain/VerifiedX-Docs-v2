## Descripción general

Compilar y emitir un contrato inteligente es bastante sencillo. El primer paso es compilar el contrato inteligente a partir de un payload JSON, que devuelve la información necesaria para el segundo paso: emitir el contrato inteligente. Luego llamas a un endpoint para emitirlo, que transmite la transacción.

## Compilación

#### Endpoint de la API:

```
POST http://localhost:7292/scapi/scv1/CreateSmartContract
```

Ejemplo de payload básico:

```json
{
  "Name": "Smart Contract Name",
  "MinterName": "Minter's Name",
  "Description": "Description Goes Here",
  "SmartContractAsset": {
    "AssetId": "00000000-0000-0000-0000-000000000000",
    "Name": "welness.jpg",
    "AssetAuthorName": "Author's Name",

  },
  "IsPublic": false,
  "SmartContractUID": "00000000-0000-0000-0000-000000000000",
```

## Emisión

#### Endpoint de la API:

```
GET http://localhost:7292/scapi/scv1/MintSmartContract/{SMART_CONTRACT_UID}
```

Ejemplo de respuesta:

```
"Smart contract has been published to mempool"
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const mintNft = async (smartContractUid) => {
  const url = `${CLI_BASE_URL}/scapi/scv1/MintSmartContract/${smartContractUid}`;
  const request = await fetch(url);

  const data = await request.text();
  if (data == "Smart contract has been published to mempool") {
    return true;
  }

  return false;
};
```

</TabItem>

```python
def mint_nft(smart_contract_uid):

    response = requests.get(url)

        return True

    return False
```

## Agregar funciones

Puedes agregar funciones a tu contrato inteligente con solo incluirlas en el arreglo `Features: []`.
Actualmente se admiten tres tipos de funciones, cada una con un valor distinto del enum `FeatureName`:

```
0: Evolving
1: Royalty
2: Multi Asset
```

:::note[Varias funciones]
Puedes combinar las tres funciones en un solo contrato inteligente, pero no puedes incluir la misma función más de una vez.
:::

### Regalía

#### Porcentaje

```json
{
    ...
    "Features": [
        {
            "FeatureName": 1,
            "FeatureFeatures":{
                "RoyaltyAmount": 0.05, // 5%
                "RoyaltyPayToAddress": "Rabc123...",
                "RoyaltyType": 1
            }
        },
    ]
}
```

### Consultar los datos

Una vez que el contrato inteligente se compila y se emite, puedes volver a leerlo a través de la API

#### Listar

```
GET http://localhost:7292/scapi/scv1/GetAllSmartContracts/{PAGE}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const listNfts = async (page = 1) => {
  const url = `${CLI_BASE_URL}/scapi/scv1/GetAllSmartContracts/${page}`;
  const request = await fetch(url);

  const data = await request.json();

  if (!data) {
    return null;
  }

  if (data["Count"] == 0) {
    console.log("No NFTs found");
    return [];
  }

  return data["Results"];
};
```

</TabItem>
