Los NFTs que tienen habilitada la evolución controlada por el emisor pueden ser evolucionados por quien los emitió, aunque ya no sea el propietario.

#### Endpoint de la API:

```text
GET http://localhost:7292/scapi/scv1/EvolveSpecific/{id}/{address}/{stage}
```

#### Parámetros de la URL:

`id`: el identificador del contrato inteligente

`address`: la dirección de VFX del propietario actual

`stage`: la etapa a la que evoluciona (la etapa original es `0`)

#### Respuesta:

El nodo devuelve la transacción de evolución. La cuenta del emisor la firma y paga la comisión de la red. El nodo devuelve el texto `Failed to Change State - TX` cuando la dirección del emisor no está en la billetera de este nodo, `address` no es el propietario actual, la etapa no existe o el saldo del emisor no alcanza para la comisión.

const evolveNft = async (smartContractUid, address, stage) => {
  const url = `${CLI_BASE_URL}/scapi/scv1/EvolveSpecific/${smartContractUid}/${address}/${stage}`;
  const request = await fetch(url);

  const data = await request.json();

  return data["Hash"];
};

## Etapa siguiente y anterior

El nodo también puede mover un NFT una etapa hacia adelante o hacia atrás. Se aplican las mismas reglas: la cuenta del emisor debe estar en la billetera de este nodo, `address` debe ser el propietario actual, y el emisor firma y paga la comisión de la red.

#### Endpoints de la API:

```text
GET http://localhost:7292/scapi/scv1/Evolve/{id}/{address}
GET http://localhost:7292/scapi/scv1/Devolve/{id}/{address}
```

#### Parámetros de la URL:

`id`: el identificador del contrato inteligente

`address`: la dirección de VFX del propietario actual

#### Respuesta:

La transacción firmada, con la misma forma que arriba. Si falla, el nodo devuelve el texto `Failed to Evolve - TX` o `Failed to Devolve - TX`.
