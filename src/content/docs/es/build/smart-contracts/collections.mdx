## Crear o actualizar una colección

#### Endpoint de la API:

```
POST http://localhost:7292/dstapi/DSTV1/SaveCollection
```

Parámetros:

```json
{
  "Id": 0,
  "Name": "My Collection",
  "Description": "My description goes here...",
  "CollectionLive": true,
  "IsDefault": false
}
```

> Usa el ID `0` si es una colección nueva. Para actualizarla, usa el ID existente de esa colección.

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const saveCollection = async (id = 0) => {
  const payload = {
    Id: id,
    Name: "My Collection",
    Description: "My description goes here...",
    CollectionLive: true,
    IsDefault: false,
  };

  const url = `${CLI_BASE_URL}/dstapi/DSTV1/SaveCollection`;
  const request = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload),
  });

  const data = await request.json();

  return data["Success"];
};
```

</TabItem>

## Listar colecciones

#### Endpoint de la API:

```
GET http://localhost:7292/dstapi/DSTV1/GetAllCollections
```

#### Respuesta:

```json
{
    "Success": true,
    "Collections": [
        {
           "Id": 1,
            "Name": "My Collection",
            "Description": "My description goes here...",
            "CollectionLive": true,
            "IsDefault": false
        },
        ...
    ]
}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const listCollections = async () => {
  const url = `${CLI_BASE_URL}/dstapi/DSTV1/GetAllCollections`;
  const request = await fetch(url);

  const data = await request.json();

  if (!data) {
    return null;
  }

  if (data["Success"] == true) {
    return data["Collections"];
  }

  return null;
};
```

</TabItem>

<TabItem label="Python">

```python
def list_collections():
    url = f"{CLI_BASE_URL}/dstapi/DSTV1/GetAllCollections"
    response = requests.get(url)
    data = response.json()

    if not data:
        return None

    if data["Success"] == True:
        return data["Collections"]

    return None

```

</TabItem>
</Tabs>

## Consultar una colección

#### Endpoint de la API:

```
GET http://localhost:7292/dstapi/DSTV1/GetCollection/{id}
```

#### Parámetros de la URL:

`id`: el ID de la colección

#### Respuesta:

```json
{
  "Success": true,
  "Collection": {
    "Id": 1,
    "Name": "My Collection",
    "Description": "My description goes here...",
    "CollectionLive": true,
    "IsDefault": false
  }
}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const retrieveCollection = async (collectionId) => {

  return null;
```

## Eliminar una colección

#### Endpoint de la API:

```
GET http://localhost:7292/dstapi/DSTV1/DeleteCollection/{id}
```

#### Parámetros de la URL:

`id`: el ID de la colección

#### Respuesta:

```json
{
  "Success": true
}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const deleteCollection = async (collectionId) => {
  const url = `${CLI_BASE_URL}/dstapi/DSTV1/DeleteCollection/${collectionId}`;
  const request = await fetch(url);

  const data = await request.json();

  return data["Success"] == true;
};
```

</TabItem>
