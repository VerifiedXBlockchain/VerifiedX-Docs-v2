## Crear una tienda

#### Endpoint de la API:

```text
POST http://localhost:7292/dstapi/DSTV1/SaveDecShop
```

Parámetros de la solicitud:

```json
{
  "Name": "Shop Name",
  "DecShopURL": "tutorial-shop",
  "Description": "My shop's description...",
  "OwnerAddress": "Rabc123...",
  "HostingType": 0,
  "AutoUpdateNetworkDNS": true
}
```

`DecShopURL` es solo el nombre: el nodo agrega `vfx://` y rechaza una URL que ya lo contenga. `HostingType` es `0` (Network), `1` (SelfHosted; envía también `IP` y `Port`) o `2` (ThirdParty). La descripción tiene un límite de 200 palabras y 1,200 caracteres. Esta llamada guarda la tienda solo en el nodo; publícala con la siguiente llamada.

#### Respuesta:

```json
{
  "Success": true,
  "Message": "Decentralized Auction Shop has been created with name Shop Name"
}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const createShop = async () => {
  const payload = {
    Name: "Shop Name",
    DecShopURL: "tutorial-shop",
    Description: "My shop's description...",
    OwnerAddress: "xDnL4MCGtgHu85JJHdN1fkXinHzKaqVQ59",
    HostingType: 0,
    AutoUpdateNetworkDNS: true,
  };

  const url = `${CLI_BASE_URL}/dstapi/DSTV1/SaveDecShop`;
  const request = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload),
  });

  const data = await request.json();

  return data["Success"];
};
```

## Publicar la tienda en la red

#### Endpoint de la API:

```text
GET http://localhost:7292/dstapi/DSTV1/GetPublishDecShop
```

Publicar envía una transacción de registro de la tienda desde la dirección del propietario. Cuesta 10 VFX más la comisión normal de la red.

#### Respuesta:

```json
{
  "Success": true,
  "Message": "Success! TX ID: abcdfg...",
  "Hash": "abcdfg..."
}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const publishShop = async () => {
  const url = `${CLI_BASE_URL}/dstapi/DSTV1/GetPublishDecShop`;
  const request = await fetch(url);

  const data = await request.json();

  console.log(data);

  return data["Success"];
};
```

</TabItem>

<TabItem label="Python">

```python
def publish_shop():
    url = f"{CLI_BASE_URL}/dstapi/DSTV1/GetPublishDecShop"
    response = requests.get(url)
    data = response.json()

    print(data)

    return data["Success"]
```

## Obtener mi tienda

#### Endpoint de la API:

```text
GET http://localhost:7292/dstapi/DSTV1/GetDecShop
```

#### Respuesta:

```json
{
    "Success": true,
    "Message": "DecShop Found",
    "DecShop": {
        ...
    }
}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const retrieveShop = async () => {
  const url = `${CLI_BASE_URL}/dstapi/DSTV1/GetDecShop`;

};
```

## Actualizar la tienda

#### Endpoint de la API:

```text
POST http://localhost:7292/dstapi/DSTV1/SaveDecShop
```

Parámetros de la solicitud:

```json
{
  "Name": "Updated Shop Name",
  "DecShopURL": "tutorial-shop",
  "Description": "My updated shop's description...",
  "OwnerAddress": "xDnL4MCGtgHu85JJHdN1fkXinHzKaqVQ59",
  "HostingType": 0,
  "AutoUpdateNetworkDNS": true
}
```

#### Respuesta:

```json
{
  "Success": true,
  "Message": "Decentralized Auction Shop has been updated with name Updated Shop Name"
}
```

`SaveDecShop` cambia solo la copia local. Publica el cambio en la red con `GetUpdateDecShop`, que envía una transacción de actualización que cuesta 1 VFX más la comisión normal de la red:

```text
GET http://localhost:7292/dstapi/DSTV1/GetUpdateDecShop
```

```json
{
  "Success": true,
  "Message": "Success! TX ID: abcdfg..."
}
```

Cuando nada cambió desde la última publicación, responde `{"Success": false, "Message": "No update is pending."}`.

## Alternar entre desconectada y en línea

#### Endpoint de la API:

```text
GET http://localhost:7292/dstapi/DSTV1/GetSetShopStatus
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const toggleShopOnline = async () => {
  const url = `${CLI_BASE_URL}/dstapi/DSTV1/GetSetShopStatus`;
  const request = await fetch(url);

  const data = await request.json();

  console.log(data);

  if (data["Success"] == true) {
    return data["Message"].replace("Is Offline? ", "") == "True";
  }

  return null;
};
```

</TabItem>

<TabItem label="Python">

```python
def toggle_shop_online():
    url = f"{CLI_BASE_URL}/dstapi/DSTV1/GetSetShopStatus"
    response = requests.get(url)
    data = response.json()

    print(data)

    if data["Success"] == True:
        return data["Message"].replace("Is Offline? ", "") == "True"

    return None
```

</TabItem>
</Tabs>

## Consultar una tienda de la red

#### Endpoint de la API:

```text
GET http://localhost:7292/dstapi/DSTV1/GetNetworkDecShopInfo/{url}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const retrieveNetworkShop = async (shopUrl) => {
  const url = `${CLI_BASE_URL}/dstapi/DSTV1/GetNetworkDecShopInfo/${shopUrl}`;
  const request = await fetch(url);

  const data = await request.json();

  if (data["Success"] == true) {
    return data["DecShop"];
  }

  return null;
};
```

</TabItem>

<TabItem label="Python">

```python
def retrieve_network_shop(shop_url):
    url = f"{CLI_BASE_URL}/dstapi/DSTV1/GetNetworkDecShopInfo/{shop_url}"
    response = requests.get(url)
    data = response.json()

    if data["Success"] == True:
        return data["DecShop"]

    return None
```

</TabItem>
</Tabs>

#### Parámetros de la URL:

`url`: URL de la tienda (por ejemplo, vfx://tutorial-shop)

#### Respuesta:

```json
{
    "Success": true,
    "Message": "Shop Found",
    "DecShop": {
        ...
    }
}
```
