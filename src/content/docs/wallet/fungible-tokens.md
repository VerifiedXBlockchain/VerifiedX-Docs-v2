## Creating Tokens
1. **Setup**:
   - In **Fungible Tokens**, click **Create Token**, then define a name and ticker symbol for your token.
   - Choose between infinite or fixed supply. A total supply of 0 means infinite supply, which allows minting.
   - Set the decimal places, and choose whether the token is burnable and allows voting.
2. **Customization**:
   - Pre-mine tokens if desired.
   - Upload a token icon for easy identification. An icon is required.
3. **Deploy**:
   - Click **Compile & Mint** to deploy the token smart contract. Its settings cannot be changed afterwards.

## Management Tools
- **Minting**: Generate additional tokens (if supply is infinite).
- **Burning**: Destroy tokens you hold (if the token is burnable).
- **Governance**: Enable voting topics for token holders.
- **Controls**: Pause transactions, ban addresses, and transfer ownership with one click.
