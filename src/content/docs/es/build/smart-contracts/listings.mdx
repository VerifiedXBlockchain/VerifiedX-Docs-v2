## Crear o actualizar una publicación

#### Endpoint de la API:

```
POST http://localhost:7292/dstapi/DSTV1/SaveListing
```

Parámetros:

```json
{
  "Id": 0,
  "CollectionId": 1,
  "SmartContractUID": "SC_ID_HERE",
  "AddressOwner": "Rabc123...",
  "BuyNowPrice": 10,
  "IsBuyNowOnly": false,
  "RequireBalanceCheck": true,
  "FloorPrice": 25,
  "ReservePrice": 30,
  "StartDate": "YYYY-MM-DDTHH:mm:ss.sssZ",
  "EndDate": "YYYY-MM-DDTHH:mm:ss.sssZ"
}
```

> Usa el ID `0` si es una publicación nueva. Para actualizarla, usa el ID existente de esa publicación.

#### Ejemplo de código

<TabItem label="NodeJS">

```js
  const url = `${CLI_BASE_URL}/dstapi/DSTV1/SaveListing`;

  return data["Success"];
};
```

## Listar publicaciones

#### Endpoint de la API:

```
GET http://localhost:7292/dstapi/DSTV1/GetCollectionListings/{collectionId}
```

#### Parámetros de la URL:

`collectionId`: el ID de la colección

#### Respuesta:

```json
{
    "Success": true,
    "Listings": [
        ...
    ]
}
```

#### Ejemplo de código

<Tabs syncKey="lang">
<TabItem label="NodeJS">

```js
const listListings = async (collectionId) => {
  const url = `${CLI_BASE_URL}/dstapi/DSTV1/GetCollectionListings/${collectionId}`;
  const request = await fetch(url);

  const data = await request.json();

  if (!data) {
    return null;
  }

  if (data["Success"] == true) {
    return data["Listings"];
  }

  return null;
};
```

</TabItem>

<TabItem label="Python">

```python
def list_listings(collection_id):
    url = f"{CLI_BASE_URL}/dstapi/DSTV1/GetCollectionListings/{collection_id}"
    response = requests.get(url)
    data = response.json()

    if not data:
        return None

    if data["Success"] == True:
        return data["Listings"]

    return None

```

## Cancelar una publicación


`id`: el ID de la publicación

```json
  "Success": true
```
